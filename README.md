# 测试用例执行器

基于 Flask + openpyxl 的轻量 Web 工具，将 Excel 测试用例变为可交互的执行界面，支持逐条浏览、标记结果、实时回写原文件；自动识别功能用例 / 场景用例 / 结果矩阵 / 信息页，并提取内嵌示意图。

## 功能特性

- **初始配置页**：填写测试阶段与测试人员，从用例库中选择文件后开始测试
- **Sheet 自动分类**：功能用例（完整执行界面）/ 场景用例（简化卡片 + 示意图 + 讲解）/ 结果矩阵与信息页（只读预览）
- **通用列解析**：按表头名（含同义词）解析列，兼容多种表头布局，不再依赖固定列序
- **内嵌图片提取**：自动提取锚定图片，场景卡片与矩阵预览中展示（按需惰性加载，不拖慢首屏）
- 按模块筛选 / 跳转下一条未测用例；键盘 ← → 与 1/2/3/4 快捷标记
- 标记 PASS / FAIL / BLOCK / 跳过，填写实际现象与发现时间（防抖自动保存）
- 执行结果原子写回原始 xlsx（首次访问自动备份，不怕丢数据）
- 实时进度条统计；支持上传 / 更换用例文件并下载回写后的版本

## 快速开始

### 方式一：双击启动（推荐）

- **macOS**：双击 `start_mac.command`
- **Windows**：双击 `start_windows.bat`

首次运行会自动创建虚拟环境 `.venv`、安装依赖，然后启动服务并打开浏览器（http://127.0.0.1:5000）。

> macOS 首次可能提示“无法打开，因为来自身份不明的开发者”，在“系统设置 → 隐私与安全性”中点击“仍要打开”即可。

### 方式二：命令行

```bash
pip install -r requirements.txt
python app.py
```

浏览器打开 http://127.0.0.1:5000 即可使用。

## 用例文件管理

- 所有用例文件统一存放在 `uploads/testing/` 目录。
- 首次启动时若该目录为空，会自动把根目录的历史文件播种进去，延续既有进度。
- 目录为空时进入初始页，可上传 `.xlsx / .xls` 文件；有文件时可直接选择开始。

## Sheet 分类规则

程序在每个 Sheet 前 6 行内定位表头行，再按表头列判定类型：

- **functional（功能用例）**：含用例标识列（用例编号 / 标题 / 用例名称）且含预期结果或测试步骤——沿用完整执行界面。
- **scenario（场景用例）**：含「场景」主列但无「标题」列——简化卡片，展示场景讲解与示意图。
- **matrix（结果矩阵）**：无逐行用例结构但存在结果网格（PASS/FAIL 等）——只读预览。
- **info（信息页）**：Sheet 名命中信息关键字（总结 / 汇总 / 策略 / bug 等级等）或无有效表头——只读预览。

仅 functional 与 scenario 进入可执行用例列表，matrix 与 info 作为只读预览。写回目标列按表头名动态解析，并幂等追加「实际现象 / 发现时间」两列。

## 技术栈

- 后端：Python / Flask / openpyxl，生产用 waitress 提供服务（未安装时自动回退 Flask 开发服务器）
- 前端：原生 HTML + CSS + JavaScript（无框架依赖）
- 写回策略：临时文件 + `os.replace` 原子替换，线程锁防并发
